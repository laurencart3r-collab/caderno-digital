# Caderno Digital

Aplicativo web para resolver fichas de exercícios escrevendo com o dedo, caneta ou mouse por cima do PDF.

## Como usar no celular

1. Acesse o site (depois de ativar o GitHub Pages).
2. Toque em **Carregar ficha** ou use o botão de upload para escolher um PDF do seu celular.
3. Escreva os cálculos com o dedo ou caneta.
4. Use borracha, desfazer e limpar conforme precisar.
5. Toque em **Exportar** para baixar a página resolvida como imagem PNG.

## Ferramentas
- Caneta (cor e tamanho ajustáveis)
- Borracha
- Desfazer
- Navegação entre páginas
- Exportação da página atual

Funciona no celular, tablet e computador.
